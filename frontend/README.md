# ClaimAI — web app

React 19 + TypeScript + Vite 8 + Tailwind CSS 4. See the [root README](../README.md) for setup.

```bash
npm run dev     # http://127.0.0.1:5173 (proxies /api to http://127.0.0.1:8010)
npm run build   # type-check and production bundle
npm run lint    # oxlint
```

Set `CLAIMAI_API_URL` to proxy `/api` to a different backend.
